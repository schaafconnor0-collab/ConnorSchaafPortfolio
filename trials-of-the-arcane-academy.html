The Trials of the Arcane Academy

Narrative Fantasy Adventure

Video Overview

Unreal Engine 5

In this video, I show off all of the core gameplay characteristics of the game Trials of the Arcane Academy. While this does not show off the completed product, it shows off all the core scripting elements for the game. In the future, I plan on recording a video that goes over how the game works within its final state that it is in now.


The Trials of the Arcane Academy is a turn-based RPG spell game. The player is enrolled in the Arcane Academy, where they learn seven spells over the course of the game. To progress in the school, the player needs to complete different trials. During these trials, they are typically tasked with completing a pre-trial escape room as well as a combat situation against a boss battle. The player will have to use their newly learned spells during the trial to help defeat the enemy. Over the course of the game, the player will learn more about the conspiracy regarding the Arcane Academy and explore themes like trust and betrayal.


My Personal Contribution

For this game, I was given a turn-based RPG template that I had to build the game on top of. The template had a basic combat, dialogue, and mission tool. For this project, I wanted to let the elements of the template shine while creating my own unique aspects of every existing part of the game, as well as building my own new parts of the game. Through the baseline of the template, I created an improved dialogue and combat system, though I largely kept the mission tool the same, as I believed that it already worked really well within the scope of the game I was going for. I was also able to create a new tool to be used within the mission system for the pre-combat escape rooms that was able to be seamlessly implemented into the mission system through my blueprint coding.


Through the game, I also created a full dialogue script that includes over 120 total interactions that the player can have over the course of this game. The dialogue system is incredibly important, as based on the answers the player gives, there can be one of two unique outcomes to the game. A player could play the game once and then again and not have the same ending if they pick different responses to dialogue throughout the game.


This project taught me a lot about different aspects of Unreal coding that I hadn't previously known. During the creation of this game, I learned how to create b-roll shots within Unreal Engine. I learned how to create a mini map, and I improved my understanding of many different aspects of character interactions, especially when it came to using transform aspects.


I also had to use C++ throughout the project to help build up the game. In the end, I transitioned most of the encounter/combat code and the entire enemy systems into C++. This made it incredibly easier to track different stats that the enemy and player have. During combat interactions, it allowed me to do much more with the system than I would have been able to do just in blueprints.
